# 2026-09-14 — FPV girl: real perspective rewrite

## What was asked
"make the 2d fpv girl more better man....more realistic and proper" — improve
`js/fpv.js` so the first-person-view woman reads as a real foreshortened body.

## Root cause found
The old FPV used a **blended depth-driven projection** (`y = topY + d*depthK +
(eyeH-h)*sc`) which maps depth *linearly* to screen-Y. Result: every part of her
body landed at a similar screen-Y, so the figure read as a flat vertical stack,
and the lateral scale was far too small (hips only ~200 px wide on a 1280 frame).

## What was done
1. **Replaced the projection with a real pitched pinhole camera.** The viewer
   kneels between her knees and leans over her, so the camera sits at
   `(dOff=0.60, eyeH=0.95)` with a 50° downward pitch:
   ```
   f = d - dOff ;  v = h - eyeH
   z  = f*cosP - v*sinP          (depth along the view axis)
   yc = f*sinP + v*cosP          (height above the view axis)
   x = cx + k*u/z ;  y = cy - k*yc/z      k = 960
   ```
   Framing achieved: crown y=61, shoulders 236, breasts 317, vulva 651,
   hips 743, hip width 372 px, head width 114 px, scale falloff 2.3x.
   Her knees fall just behind the lens plane, so they correctly leave frame.

2. **Fixed a severe L/R inversion.** `axilL` was computed on the *screen-right*
   while `hipL` was on the *screen-left*, so the torso silhouette path jumped
   across the trunk and **self-intersected, drawing a dark bowtie across her
   chest**. The same inversion made the two legs cross in an X. Both fixed by
   making every `*L` landmark consistently `u < 0`.

3. **Neck** was a lampshade (flared to 1.86x = 174 px wide). Now a 0.076 m
   column with a gentle 1.32x trapezius flare, filled with the same directional
   light as the torso. Throat shadow moved *below* the chin line (it was hidden
   behind the face, which made her snout). Added an under-jaw shadow.

4. **Breasts** were detached outlined spheres centred on the ribcage edges.
   Now centred 0.092 m off the midline with a rim that fades to transparent so
   they melt into the chest; removed the rivet-like Montgomery tubercles.

5. **Head** was a looming mask (80 px hair mass at ~0.96 scale). Now sized in
   metres against the local projection scale (hs ~1.02 → ~90 px face).

6. **Arms** projected *off the top of the screen* (wrist y = -34) because
   `elD`/`haD` used `B.shoulder + 0.20/+0.40` — running *away* from the lens.
   Fixed to run down her body toward the lens. Shoulder root moved inboard and
   lower so it stops reading as an epaulette.

7. **Torso gradient** now spans from above the clavicle to below the hips; it
   used to clamp to its lightest stop across the whole upper chest, producing a
   flat bright "collar". Shoulder line rebuilt as a trapezius slope.

8. **Face vs body tone mismatch** — the face used a base→shadow gradient while
   the trunk used highlight→shadow, so the face read a full stop darker than the
   body it belonged to. Face now uses the same tone range.

9. **`shade()` in `js/gfx.js` was drawing a circular gradient inside an
   elliptical clip**, so elongated AO pools kept up to 86% alpha at their rim and
   showed as hard-edged pasted-on ovals. Rewrote it to scale the context to the
   ellipse so the gradient reaches 0 alpha exactly at the rim. This is a shared
   primitive — side.js was re-rendered to confirm no regression.

## Harness bug fixed (important)
`scratch/verify2d.mjs` never forced the viewport, so Chrome's window chrome
shrank the capture to **1262x568 instead of 1280x720** — every screenshot was
vertically squashed 20%, which made all visual judgement unreliable. Fixed with
`Emulation.setDeviceMetricsOverride`. **Always check the PNG is 1280x720.**
