## Full 3D mode (Three.js) — new entry `3d.html`

User asked for a "full 3d mode" of the game, keeping 2D intact. Built a complete
Three.js renderer that REUSES the shared game logic and swaps only the view layer.

### Architecture (key decision)
- New entry `3d.html`. Loads: `vendor/three.min.js` (r150 UMD, vendored locally so
  it works offline + `file://`) → shared `js/core,audio,chars,input,mechanics` →
  **also loads `js/gfx,side,fpv,poses,oral`** (for shared API only: `herExpression()`,
  `POSES/cyclePose/posName`, `toggleOral()`) → `js/charui` → `js3d/*`.
- Replaces `js/app.js` with `js3d/app3d.js`. 2D files UNTOUCHED.
- `#scene` hidden canvas kept so `core.js` can grab a 2D context; `#scene3d` is the
  WebGL canvas. Verified no shared module references `X`/`CV` beyond core.js decl.

### js3d/ modules (all node --check OK, 18-script bundle parses, 0 dup definitions)
- `engine3d.js` (560 ln): WebGLRenderer+shadows+ACES, toon cel shading via
  `MeshToonMaterial` + banded `gradientMap` (ramp), inverted-hull outline shader,
  warm lamp key + cool moon rim + counter-rim lights, bedroom set (bed/nightstand/
  lamp/window+moon). **Camera rig** orbit/side/top/fpv with smooth lerp + shake.
  **Skin helpers**: `makeSkinTex3()` (seeded-noise pores + warm mottling canvas
  texture), `makeSheenMat3()` (Fresnel additive shell = glossy anime skin),
  `skinMat3()`, `addSheen3()`.
- `chars3d.js` (602 ln): procedural anime figures. `buildHer3()` 56 meshes,
  `buildHim3()` 33 meshes. Head = sphere + canvas-painted face patch
  (`paintFace3` draws big glossy eyes/blush/brows/mouth from `herExpression()`,
  mapped onto curved SphereGeometry patch). Hair = scalp cap + tapered TubeGeometry
  tresses. Full rig: hips/torso/chest/neck/head, 2-bone arms/legs, breasts, shaft.
- `poses3d.js` (245 ln): 7 positions + oral as joint-angle targets mirroring
  `js/poses.js` order (0 missionary·1 legs-up·2 doggy·3 prone·4 cowgirl·5 rev·6 spoon).
  `orientTo3()` builds rotation via `makeBasis` with **Gram-Schmidt ortho-fix**
  (critical: spoon/oral hand-authored tilted fwd vectors would otherwise shear the rig).
  `lerpPose3()` blends transitions; `applyPoseCam3()` nudges camera per pose.
  World anchors: `vulvaWorld3/shaftTipWorld3/breastWorld3`.
- `anim3d.js` (252 ln): applies poses (smoothed), thrust slides his pelvis along
  line-to-her by `G.depth`, breathing chest scale, spring breast/butt jiggle from
  `G.impact`, 2-bone IK arm aiming (`aimArmAt3`) for rub hands on 4 zones, oral head
  bob, orgasm arch+tremble, afterglow slump, face repaint throttled to 26fps.
- `fx3d.js` (294 ln): shader-based particle pools (per-particle alpha+size) for
  climax jets (gravity 9.0, spawn on `G.spurts` change), vulva drips, sweat, glisten,
  hearts; DOM screen flash + camera shake. `clearFX3()` on round change.
- `app3d.js` (200 ln): loop calls shared `update(dt)` + `updateAnim3/updateFX3/
  updateCamera3/hudTick3`. Own HUD sync (app.js not loaded). Sets `dragK` for input.js.
  Live char-customization material re-tint + full rebuild on preset change.
